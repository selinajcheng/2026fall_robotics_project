## **Software Requirements**

| Software | Purpose |
| ----- | ----- |
| Python 3 | Main programming language for robot navigation and movement |
| Pygame | Creates the 2D visual simulation and animates the robot |
| VS Code | Writing, running, and debugging Python code |
| Git | Tracks code changes |
| GitHub | Stores project files and handles submissions |

### **Algorithms**

\- A Pathfinding:\* Implemented in Python to calculate routes around obstacles. No separate installation required.

### **Installation**

Install Pygame using:

python3 \-m pip install pygame

No additional robotics software is required. Python and Pygame will handle the entire simulation.
